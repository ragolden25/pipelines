=== nucleus-images.yml
---
# Find, copy, GPG-verify, and load the hardened nucleus images.
# ───────────────────────────────────────────────
# Stage: Copy nucleus images
# ───────────────────────────────────────────────

- name: Find nucleus images in avocado files
  ansible.builtin.find:
    paths: "{{ avocado_artifact_dir }}/images"
    patterns: "nucleus-*.tar.gz"
  register: nucleus_src_images
  delegate_to: localhost

- name: Copy nucleus images to target host
  ansible.builtin.copy:
    src: "{{ item.path }}"
    dest: "/var/lib/containers/images/{{ item.path | basename }}"
    mode: "0640"
  loop: "{{ nucleus_src_images.files }}"
  loop_control:
    label: "{{ item.path }}"

# ───────────────────────────────────────────────
# GPG Signature Verification
# ───────────────────────────────────────────────

- name: Ensure gpgkeys directory exists
  ansible.builtin.file:
    path: /var/lib/containers/gpgkeys
    state: directory
    mode: '0755'

- name: Copy GPG public key
  ansible.builtin.copy:
    src: "{{ avocado_artifact_dir }}/gpgkeys/ansible.pub"
    dest: "/var/lib/containers/gpgkeys/ansible.pub"
    mode: "0644"

- name: Import GPG public key
  ansible.builtin.shell: |
    gpg --import /var/lib/containers/gpgkeys/ansible.pub
  args:
    executable: /bin/bash

- name: Find nucleus signature files
  ansible.builtin.find:
    paths: "{{ avocado_artifact_dir }}/provenance/nucleus"
    patterns: "nucleus-*.tar.gz.asc"
  register: nucleus_signature_files
  delegate_to: localhost

- name: Copy nucleus signature files to target host
  ansible.builtin.copy:
    src: "{{ item.path }}"
    dest: "/var/lib/containers/images/{{ item.path | basename }}"
    mode: "0640"
  loop: "{{ nucleus_signature_files.files }}"
  loop_control:
    label: "{{ item.path }}"

- name: Verify GPG signatures for all nucleus images
  ansible.builtin.shell: |
    gpg --trust-model always \
        --verify "/var/lib/containers/images/{{ item.path | basename }}.asc" \
                 "/var/lib/containers/images/{{ item.path | basename }}"
  args:
    executable: /bin/bash
  loop: "{{ nucleus_src_images.files }}"
  loop_control:
    label: "{{ item.path }}"
  register: gpg_verify
  failed_when: gpg_verify.rc != 0

- name: Fail if any image signature verification failed
  ansible.builtin.fail:
    msg: "One or more GPG signature checks failed."
  when: gpg_verify.results | selectattr('rc', 'ne', 0) | list | length > 0

# ───────────────────────────────────────────────
# Stage: Load images
# ───────────────────────────────────────────────

- name: Find hardened nucleus images
  ansible.builtin.find:
    paths: "/var/lib/containers/images"
    patterns: "nucleus-*.tar.gz"
  register: found_images

- name: Fail if no nucleus images found
  ansible.builtin.fail:
    msg: "No nucleus images found on target host."
  when: found_images.files | length == 0

- name: Load ALL verified nucleus images
  ansible.builtin.shell: docker load -i "{{ item.path }}"
  args:
    executable: /bin/bash
  loop: "{{ found_images.files }}"
  loop_control:
    label: "{{ item.path }}"

That only affects documentation, but it means every deployment’s README says nginx 1.31.6 regardless of what’s actually running. Here are the two fixes (as ansible). Both keep a backup.

1. README: use the same version variables the compose file uses

sed -i.bak -E 's/\{\{ hostvars\[inventory_hostname\]\.(guacamole|guacd|postgres|nginx)_version \}\}/{{ \U\1\E_VERSION }}/' /opt/ansible/nucleus/roles/configure_guacamole/templates/README.md.j2

2. Remove the pinned versions from vars/main.yml

sed -i.bak '/^# Versions$/,/^nginx_version:/d' /opt/ansible/nucleus/roles/configure_guacamole/vars/main.yml

This deletes the # Versions heading and the four version lines. The # ─── divider line above the heading stays, which is harmless. Check the result with grep -n version /opt/ansible/nucleus/roles/configure_guacamole/vars/main.yml, which should print nothing.

I’ve assumed the uppercase version variables are available to all of the role’s templates, since docker-compose.yml.j2 uses them the same way. If README generation errors with an undefined variable, restore it with mv README.md.j2.bak README.md.j2 and paste the error.
